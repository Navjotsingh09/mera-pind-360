Village Library & Tools

Reading rooms, competitions, and shared tools that make everyday problem-solving local again.

Programme Overview

How this programme works in the 360 model.

The village library is designed as both a learning space and a practical commons. Children find books and quiet study space, while families can access shared household tools that reduce cost and keep small jobs moving.

Key Focus Areas

  • Reading spaces that stay relevant to children and families
  • Reading competitions and community learning activity
  • Shared tools library for practical village use
